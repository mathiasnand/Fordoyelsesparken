# Fordøyelsesparken Design Charter

Version 0.1

---

# Purpose

The purpose of this document is to define the visual identity and design principles for every manual within the Fordøyelsesparken universe.

These guidelines ensure that every document feels like it originates from the same professional creative studio.

---

# Core Philosophy

Design should always communicate:

• Professionalism
• Creativity
• Clarity
• Consistency
• Timelessness

Function always comes before decoration.

---

# Document Style

Every manual should feel like:

- an internal studio handbook
- a professional design manual
- a premium publication

Never like an ordinary school report or Word document.

---

# Layout Principles

• A4 Portrait
• Large margins
• Generous whitespace
• Strong visual hierarchy
• One clear purpose per page

---

# Typography

Maximum two font families.

Typography should be elegant, readable and timeless.

---

# Colour System

Each manual has its own primary colour while sharing the same visual language.

Book Bible
→ Navy Blue

Master Bible
→ Burgundy

Character Bible
→ Orange

Design Bible
→ Purple

Parkatlas
→ Green

Fact Library
→ Turquoise

---

# Components

Every recurring element should become a reusable component.

Examples:

- Header
- Footer
- Chapter Title
- Fact Box
- Quote
- Image Frame
- Timeline
- Table
- Callout

---

# Design Rule

If a design element does not improve communication,
remove it.

Less is more.
